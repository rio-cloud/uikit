# UIKIT

[UIKIT](https://uikit.developers.rio.cloud/latest/) is a design system for
designing and building consistent web applications. It brings reusable React
components, Foundation CSS utilities, design tokens, patterns, and practical
guidelines together in one place.

Developers and designers can use the same foundations for layouts, typography,
colors, spacing, and interactions. The component library is built with
TypeScript and supports brand themes, responsive layouts, and dark mode.
Interactive documentation provides live examples, source snippets, and component
properties to help you put those pieces to work.

## About this repository

This is the public home for UIKIT feedback, bug reports, and feature requests.
Use Issues to share your experience, discuss improvements, and follow up on
reported problems or proposed features.

The UIKIT implementation and build tooling are maintained separately. To use
UIKIT in your application, install the npm package and follow the
[documentation](https://uikit.developers.rio.cloud/latest/#/docs).

## Get started

1. **Explore the system.** Visit the
   [design system overview](https://uikit.developers.rio.cloud/latest/#/design-system)
   to understand the shared visual and interaction foundations.
2. **Set up your project.** Follow the
   [installation guide](https://uikit.developers.rio.cloud/latest/#/docs/start/installation)
   for project setup, supported React versions, styling, and initialization. For
   an existing React application, install the package with:

   ```bash
   npm install @rio-cloud/rio-uikit
   ```

   Use the documentation version that matches your installed package. Wrap your
   application in `ApplicationLayout` to initialize UIKIT and its managed theme
   styles as described in the guide.
3. **Build your first screen.** Browse the
   [components](https://uikit.developers.rio.cloud/latest/#/docs/components),
   try the playgrounds, and use their code examples. Start with a
   [Button](https://uikit.developers.rio.cloud/latest/#/docs/components/button),
   or explore the [templates](https://uikit.developers.rio.cloud/latest/#/docs/templates)
   for larger compositions.
4. **Use the shared foundations.** Explore
   [Foundation CSS](https://uikit.developers.rio.cloud/latest/#/docs/foundations)
   for layout, spacing, typography, colors, and responsive behavior, alongside
   [hooks](https://uikit.developers.rio.cloud/latest/#/docs/hooks) and
   [helpers](https://uikit.developers.rio.cloud/latest/#/docs/helper).

Working with an AI coding assistant? The
[UIKIT MCP server setup](https://uikit.developers.rio.cloud/latest/#/docs/start/guidelines/uikit-mcp-server)
explains how to connect structured UIKIT knowledge and the accompanying agent
skill so your assistant can use the documented components and conventions.

For updates to an existing project, see the
[changelog](https://uikit.developers.rio.cloud/latest/#/docs/start/changelog) and
[migration guides](https://uikit.developers.rio.cloud/latest/#/docs/start/migration-guides).

## UIKIT Studio

[UIKIT Studio](https://uikit.developers.rio.cloud/latest/#/studio) helps you turn
ideas into interactive UIKIT prototypes. Describe what you want to build in
natural language, try the result on the canvas, and refine it with annotations,
text changes, or the built-in code editor. You can compare revisions, explore
brand themes, and export a runnable React/TypeScript project for further
development.

Visit the [Studio overview](https://uikit.developers.rio.cloud/latest/#/studio)
to explore the workflow, or head to the
[UIKIT Studio repository](https://github.com/rio-cloud/uikit-studio) for the beta
and Studio-specific feedback.

## Feedback and requests

Use GitHub Issues to help improve UIKIT:

- [Report a bug](https://github.com/rio-cloud/uikit/issues/new?template=bug-report.yml)
- [Give feedback](https://github.com/rio-cloud/uikit/issues/new?template=feedback.yml)
- [Request a feature](https://github.com/rio-cloud/uikit/issues/new?template=feature-request.yml)

Check the [existing issues](https://github.com/rio-cloud/uikit/issues) first. If
someone has already reported the same problem or idea, add relevant details to
that issue.

The **Feedback** button in each documentation playground opens the appropriate
form with the component, example, documentation link, and UIKIT version already
included. You can then add a description and screenshots on GitHub before
submitting the issue. A GitHub account is required. Issues are public.
